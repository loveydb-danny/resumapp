텀블벅 상세페이지의 이미지와 카피를 재구성한 **앱 설치 유도 페이지**.
목표는 감성 전달 + 설치 전환, 모바일 우선.

- 최종 개편: 2026-08-04
- 예정 주소: `loveydb.com/resumapp` → 추후 `resum.co.kr`로 이전 가능
- 참고 구조: 감쟈일기(gamzadiary.com) — 정보 위계만 참고, 디자인은 미참고

## 1. 미리보기

`index.html`을 **더블클릭**하면 브라우저에서 바로 열린다.

휴대폰에서 보려면 터미널에서:

```bash
cd ~/resum_marketing/landing
python3 -m http.server 8899
```

같은 와이파이의 휴대폰에서 `http://<맥의 IP>:8899` 접속.
맥 IP는 `ipconfig getifaddr en0`으로 확인.

## 2. 설계 의도

**텀블벅 상세페이지를 그대로 옮기지 않았다.** 텀블벅은 돈을 내게 만드는 긴 설득 구조지만,
무료 앱 설치는 마찰이 거의 없어서 **짧고 강한 감정 한 방**이 더 잘 먹힌다.

| 원칙 | 적용 |
|---|---|
| 감정선을 위로 | 히어로 바로 다음이 "우리 갔던 카페가 어디였지?" — 앱 설명보다 아픈 질문이 먼저 |
| 핵심 기능 2개만 크게 | 추억 문답 · 쪽지 숨기기. 나머지 3개는 **가로 스와이프 카드**로 접음 |
| 설치 버튼 3곳 + 고정바 | 첫 화면 · 마지막 · 모바일 하단 고정바(히어로를 지나면 등장) |
| 감성은 서체와 호흡으로 | 서술은 **명조체**, 스크롤에 따라 부드럽게 등장 |

## 2-1. 디자인 시스템 (4차 개편에서 도입)

### 격자 — 페이지를 관통하는 세로선 하나

**모든 텍스트·라벨·버튼이 `--gutter` 한 값 위에 왼쪽으로 걸린다. 가운데 정렬을 쓰지 않는다.**
정렬이 어긋날 여지를 구조적으로 없애는 방식이자, 한국 앱 랜딩(토스·29CM)의 지배적 패턴이다.

```
.band   화면 폭 전체 — 배경색만 담당
.grid   안쪽 콘텐츠 — 거터를 만드는 유일한 지점 (width:100%, max-width:--col)
.bleed  .grid 안에서 거터를 무효화해 화면 끝까지 나가는 미디어
```

이미지만 이 선을 넘을 수 있고, 넘을 땐 **반드시 화면 끝까지** 간다. 어중간한 여백은 없다.

**측정으로 검증함** — 모바일 390px에서 텍스트 요소 26개가 전부 `left=20px`,
데스크톱 1100px에서 25개가 전부 `left=274px`. 가로 넘침 0.

> ⚠️ `.grid`의 `width:100%`를 지우면 안 된다. 부모가 flex일 때 `margin-inline:auto`가
> flex 자동 마진으로 해석돼 콘텐츠 폭만큼 줄어들면서 거터선이 무너진다.
> 실제로 이 개편 중에 한 번 깨졌고 측정으로 잡았다.

### 토큰

| 종류 | 값 |
|---|---|
| 여백 | `--s-1…--s-18` (4px 배수). 레이아웃 여백은 전부 여기서만 꺼내 쓴다 |
| 글자 | `--fs-label/small/body/title/h2/h1` — 720px에서 한 번 커진다 |
| 격자 | `--gutter` 20px(→24px) · `--col` 600px · `--measure` 30rem(한글 30자) |

섹션 안 블록 간격은 **`gap` 하나로만** 만든다. 개별 요소에 margin을 주면 값이 흩어지고 상쇄가 생긴다.

### 색 — 회색을 쓰지 않는다

중간톤을 순수 회색으로 두면 "고르지 않은" 인상이 된다. 전부 악센트 쪽으로 색기를 기울였다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--ink` | `#1b1416` | 붉은기 도는 먹색 (본문·제목) |
| `--ink-2` | `#6e6166` | 모브 기운의 보조 텍스트 |
| `--paper` / `--paper-2` | `#ffffff` / `#f6f1ef` | 섹션 교차 |
| `--accent` | `#e8385a` | 깊은 로즈 — **라벨과 밑줄에만** |
| `--blush` | `#f7d3ce` | 앱 UI의 분홍 — 형광펜 자국에만 |

**단일 라이트 테마**를 의도적으로 택했다. 소재 이미지가 전부 밝은 주광 사진이라
다크 그라운드를 두면 이미지 주변에 헐레이션이 생긴다.

### 서체 — 말의 성격을 서체로 나눈다

장식이 아니라 역할 구분이다.

- **나눔명조**(`.tell`) = **서술** — 감정·이야기. 히어로, 감정 인용, 마무리
- **Pretendard** = **지시** — 기능 제목, 설명, 버튼, 라벨

### 세로 길이 변화 (모바일 390px 기준)

| 버전 | 높이 |
|---|---|
| 1차 — 텀블벅 이미지 17장만 | 6,640px |
| 2차 — 카피 추가 | 7,415px |
| 3차 — 구조 개편 | 5,765px |
| **4차 — 디자인 시스템 (현재)** | **6,091px** |

3차보다 5% 늘었다. 격자 여백을 스케일로 통일하면서 섹션 호흡이 커진 값이고,
읽는 리듬을 위해 그대로 뒀다. 더 줄이려면 `--sec-y`를 한 단계 낮추면 된다.

## 3. 구성

```
landing/
├── index.html          # 페이지 전체 (HTML+CSS+JS 한 파일)
├── images/             # 사용 중인 이미지 9장 + 데모 영상 1개
│   └── _unused/        # 뺀 이미지 (되살리려면 여기서 꺼내 쓰면 됨)
└── assets/             # 로고·앱아이콘·스토어배지·공유이미지
```

**섹션 순서**

| # | 섹션 | 바탕 | 내용 |
|---|------|------|------|
| 1 | 히어로 | 흰색 | `1.webp` + "기억이 아닌, '추억'을 남기기 위해"(명조) + 설치 버튼 |
| 2 | 감정선 | 오프화이트 | 아픈 질문(명조) → `2.webp` → "장소와 함께 남겨두면"(명조) |
| 3 | Point 1 | 흰색 | 그날 그 장소에 맞춘 질문 → `5.webp` `6.mp4` |
| 4 | Point 2 | 오프화이트 | 어릴 때 보물찾기 → `13.webp` → 명조 인용 → `16.webp` |
| 5 | 더 보기 | 흰색 | 가로 스와이프 카드 3장(`7·9·11.webp`) + 출시 예정 2건 |
| 6 | 마무리 | 그라데이션 | `17.webp` → 설치 CTA → 푸터 |

섹션 구분은 **가운데 정렬이 아니라 바탕색 교차**로 만든다.

**사용하지 않는 이미지**: `3·4·8·10·12·14·15` — 중복이거나 텍스트로 대체됨.
`images/_unused/`에 보관돼 있어 언제든 되살릴 수 있다.

## 5. 넣어둔 기능

- **모바일 하단 고정 설치바** — 히어로를 지나면 올라옴. 전환의 핵심 장치
- **OS 자동 감지** — 아이폰이면 App Store 배지가 앞에, 안드로이드면 Play가 앞에
- **유입 경로 추적** — 페이지에 붙은 `?utm_source=…`를 스토어 링크까지 전달
  (iOS `ct=`, Android `referrer=`). 채널별 설치 기여 측정용
- **카카오톡·인스타 공유 카드** — OG 태그 + 전용 이미지
- **iOS 사파리 스마트 배너** — 상단에 앱 설치 배너 자동 노출
- GIF(15MB) → MP4 변환으로 용량 83% 절감. 전체 2.6MB

### 스크롤 등장 효과의 안전장치 ⚠️

등장 효과는 요소를 처음에 **투명하게 숨겼다가** 스크롤에 맞춰 보여주는 방식이다.
스크롤 이벤트가 오지 않는 환경(구형 인앱 브라우저 등)에서 콘텐츠가 영영 안 보일 수 있어
두 가지를 걸어뒀다.

1. **설치 CTA에는 등장 효과를 아예 걸지 않았다** — 전환의 핵심이라 무조건 보여야 함
2. **6초 실패 대비 타이머** — 그때까지 숨어 있는 요소는 전부 강제로 노출

효과를 통째로 끄고 싶으면 JS의 `document.documentElement.classList.add('js-anim')` 한 줄을 지우면 된다.

### UTM 사용 예

```
loveydb.com/resumapp?utm_source=ig&utm_medium=bio&utm_campaign=official_bio   # 공식 계정
loveydb.com/resumapp?utm_source=ig&utm_medium=bio&utm_campaign=toon_bio       # 인스타툰
loveydb.com/resumapp?utm_source=meta&utm_medium=paid&utm_campaign=voc_appeals # 메타 광고
```
